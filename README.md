# CHRSTPHR Site — Stitched Prototype

A static HTML prototype of the CHRSTPHR personal brand site. Seven pages, fully linked, no build step required.

## Pages

| File              | Page         | Notes                                                                 |
|-------------------|--------------|-----------------------------------------------------------------------|
| `index.html`      | Home         | Cursor-spotlight CHRSTPHR frame, draggable stickers, marquee, About   |
| `work.html`       | Work         | Featured project + 8-card grid + sample case study layout             |
| `experience.html` | Experience   | Resume — Timeline ↔ Cards toggle, real content from your PDF          |
| `skills.html`     | Skills       | Vending machine with legs + shelves, 12 skills, LCD display, FAQ      |
| `how-i-work.html` | How I Work   | 5-phase process, 8 principles, tools + rituals (Adobe CC tooltip)     |
| `contact.html`    | Contact      | Void form (default) + classic CRT terminal alt with auto-typing       |
| `404.html`        | 404 / Lost   | Runaway zero, "lost since" timer                                      |

## How to view

Open any `.html` file directly in a browser — no server needed.

The top-bar navigation is wired across all pages. The current page is highlighted in orange.

## Brand system

- **Bg:** `#0A0A0A`
- **Fg:** `#F2EDE2`
- **Accent:** `#FF4500` (blood orange)
- **Display:** Arial Black, italic for emphasis
- **Mono:** Courier New (terminal + LCD readouts)

## Sound

Each page has a sound toggle (bottom-right). Default is **on** — first interaction will start the audio context.

## To deploy

Drop the entire `site/` folder onto any static host (Netlify, Vercel, GitHub Pages, S3, plain web server).

## To replace placeholder content

- **Work cards** in `work.html`: search for `class="project"` blocks
- **Real case study text**: `class="case-study"` block at bottom of `work.html`
- **Resume content** in `experience.html` is already real
- **Skills items** in `skills.html`: the `skills` array in the `<script>` block
